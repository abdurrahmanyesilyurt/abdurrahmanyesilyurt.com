# Security Policy

## Reporting a vulnerability

If you find a security issue in this website or repository, please report it privately through
[GitHub private vulnerability reporting](https://github.com/abdurrahmanyesilyurt/abdurrahmanyesilyurt.com/security/advisories/new)
instead of opening a public issue.

Please include the affected URL or file, the steps to reproduce it and the impact you expect.
I will acknowledge your report as soon as possible and keep you updated until it is resolved.

The same contact is published in machine-readable form at
[`/.well-known/security.txt`](https://www.abdurrahmanyesilyurt.com/.well-known/security.txt).

## Scope

- https://www.abdurrahmanyesilyurt.com and all of its pages (the apex domain redirects there)
- The source code in this repository

The site is fully static: it has no user accounts, forms, cookies or server-side code.

## Supported versions

Only the version currently deployed from the `main` branch is supported.
